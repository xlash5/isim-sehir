# İsim Şehir — v3.0 Progressive Web App (PWA) Support

> **Priority:** P03 — nice-to-have enhancement for installability and offline support
> **Version target:** v3.0
> **Status:** 🔵 Draft

## Overview

The application is a standard web SPA with no PWA capabilities. Users must open the browser and navigate to the URL each time. This spec adds a service worker and web app manifest so the app can be installed on mobile and desktop home screens, with basic offline support for the landing page and cached assets.

## Requirements

### 1. Web App Manifest

Create `public/manifest.json`:

```json
{
  "name": "İsim Şehir",
  "short_name": "İsim Şehir",
  "description": "Multiplayer word game — classic Turkish İsim Şehir",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#0a1929",
  "theme_color": "#0a1929",
  "icons": [
    { "src": "/icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "/icon-512.png", "sizes": "512x512", "type": "image/png" },
    { "src": "/icon-512-maskable.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" }
  ]
}
```

- Theme colour matches the dark theme default (`#0a1929`).
- Icons are generated from a high-res source (preferably the existing `vite.svg` or a new logo).

### 2. Service Worker

Use `vite-plugin-pwa` to generate the service worker with Workbox:

| Strategy | Routes | Behaviour |
|---|---|---|
| `StaleWhileRevalidate` | Static assets (JS, CSS, fonts) | Fast load with background updates |
| `NetworkFirst` | `/` (index.html) | Always try network first, fallback to cache |
| `NetworkOnly` | `/room/*`, `/game/*` | Never cache — game state must be fresh |

The service worker:
- Is registered on app load (with a brief delay to not block initial render).
- Shows a "Yeni sürüm mevcut. Güncellemek için tıklayın." toast when a new version is detected (skipWaiting + clientsClaim).
- Does NOT cache any game data (WebRTC signalling, peer messages, state).
- Caches locale files (`/assets/locales/*.json`) with `StaleWhileRevalidate`.

### 3. Installation Prompt

- On mobile (Chrome Android, Samsung Internet): the browser's native install prompt appears when the user visits twice with 5+ minutes between visits.
- On desktop: the address bar shows an install icon.
- Custom "Uygulamayı Yükle" button in the home page that triggers the `beforeinstallprompt` event programmatically.
- Track `appinstalled` event for analytics (via the Sentry integration from P01-02).

### 4. Offline Landing Page

When offline:
- The home page (nickname entry, create/join buttons) works from cache.
- The rules panel (from `P01-01`) works from cache — a new player can read the rules even without connectivity.
- Attempting to navigate to a room or game while offline shows an offline-specific error state: *"İnternet bağlantısı yok. Lütfen bağlantınızı kontrol edin."*

### 5. Icon Generation

- Source: A high-res SVG (preferably the existing `public/vite.svg` or a new design).
- Generated sizes: 192x192, 512x512, 512x512 (maskable).
- Use `@vite-pwa/assets-generator` or a manual generation script.

## Technical Design

### Dependencies to Add

| Package | Type | Purpose |
|---|---|---|
| `vite-plugin-pwa` ^0.20 | devDep | Service worker + manifest generation |
| `@vite-pwa/assets-generator` | devDep | Generate PWA icons from source SVG |

### Vite Configuration

```ts
// vite.config.ts (add to plugins)
import { VitePWA } from 'vite-plugin-pwa'

VitePWA({
  registerType: 'autoUpdate',
  includeAssets: ['icon-192.png', 'icon-512.png', 'icon-512-maskable.png'],
  manifest: {
    // ... manifest.json content (imported or inlined)
  },
  workbox: {
    globPatterns: ['**/*.{js,css,html,woff2}'],
    runtimeCaching: [
      {
        urlPattern: /\/locales\/.*\.json/,
        handler: 'StaleWhileRevalidate',
      },
    ],
  },
})
```

### Service Worker Update Handling

```ts
// src/pwa.ts — registration + update handling
import { registerSW } from 'virtual:pwa-register'

const updateSW = registerSW({
  onNeedRefresh() {
    // Show update toast
    useNotificationStore.getState().show({
      message: 'Yeni sürüm mevcut. Güncellemek için tıklayın.',
      severity: 'info',
      action: {
        label: 'Güncelle',
        onClick: () => updateSW(true),
      },
    })
  },
  onOfflineReady() {
    console.log('[PWA] App ready for offline use')
  },
})
```

### Icon Generation (package.json script)

```json
{
  "scripts": {
    "pwa:generate-icons": "pwa-assets-generator --preset minimal public/vite.svg"
  }
}
```

### Files to Create

- `public/manifest.json` (generated by vite-plugin-pwa, but a source template is helpful)
- `src/pwa.ts` — service worker registration + update handler
- `public/icon-192.png`, `public/icon-512.png`, `public/icon-512-maskable.png` (generated)

### Files to Modify

- `vite.config.ts` — add VitePWA plugin
- `index.html` — add `<link rel="manifest">` (auto-injected by plugin)
- `src/main.tsx` — import `pwa.ts` for registration
- `src/pages/HomePage.tsx` — add "Uygulamayı Yükle" button
- `src/locales/*.ts` — add PWA-related strings

### Locale Keys to Add

| Key | Turkish | English |
|---|---|---|
| `pwa.install` | Uygulamayı Yükle | Install App |
| `pwa.updateAvailable` | Yeni sürüm mevcut. Güncellemek için tıklayın. | New version available. Click to update. |
| `pwa.offline` | İnternet bağlantısı yok. | No internet connection. |
| `pwa.offlineReady` | Uygulama çevrimdışı kullanıma hazır. | App ready for offline use. |

## Acceptance Criteria

- [ ] App can be installed on Chrome Android (adds to home screen)
- [ ] App can be installed on Chrome Desktop (install icon in address bar)
- [ ] Installed app opens in standalone mode (no browser chrome)
- [ ] Home page loads from cache when offline
- [ ] Rules panel loads from cache when offline
- [ ] Update toast appears when new version is deployed
- [ ] Game pages return offline error gracefully (not a broken white page)
- [ ] Lighthouse PWA audit passes (≥90 on all categories)
- [ ] All PWA icons render correctly on different devices
